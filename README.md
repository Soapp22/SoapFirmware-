## Modules (setup)

Display 	VCC → 3V3	GND → GND	SCL → G5	SDA → G4

Buttons	    UP → G27	DOWN → G26	OK → G33	BACK → G32

CC1101	    1 → GND	2 → 3V3	3 → G4	4 → G5	5 → G18	6 → G23	7 → G19

IR	        IR-TX → G1	IR-RX → G2
